Cuándo usar cada una

  • twr-macos-design: nuevos flujos, refinamientos visuales, temas y composición. Invocación explícita: $twr-macos-design.
  • twr-interaction-review: movimiento y revisión del flujo en la app real. Invocación: $twr-interaction-review.

Si una sesión existente no descubre las skills recién incorporadas, leer sus archivos por ruta. La presencia en disco no prueba que un chat ya abierto las haya cargado.

Fuentes y adaptación

La base conceptual es GPUI Kit Design Guides, complementada por Apple HIG y el método de crítica visual de Impeccable. Las referencias para agentes detallan el uso y los límites. Los archivos provenance.json fijan commits y hashes de fuentes upstream consultadas. La redacción es propia de TWR; no se redistribuyen ejecutables, snippets ni manuales de terceros.

Criterios de revisión

Usar datos sintéticos para abrir un proyecto, seleccionar un archivo, dividir un panel, abrir y cancelar un overlay y continuar escribiendo. Verificar foco y selección, tamaños de ventana, temas y estados relevantes. Si hay movimiento, comprobar interrupción y alternativa sin animación. El resultado visual y el rendimiento deben reportarse con evidencia distinta.

Alcance

Estas skills no cambian la UI por sí mismas ni autorizan builds, merges, releases o reanudar un goal pausado. Las pruebas automatizadas y el profiling se usan solo cuando el usuario los autoriza y el cambio lo requiere. No hay scripts ni procesos nuevos que operar.
